## The roast

> My wireless earbuds always die in the left one first, every single
> time, like the pair agreed the left one does all the work and the
> right one just takes the credit.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (standard library only, no network) writes the line to
`entry.txt` in the output directory, after checking it is one line
of 1 to 200 characters.
